④ 特殊假名

っ / ッ
促音

把后面辅音发成堵住再放开，罗马音双写：かった = katta，がっこう = gakkou。

ー
长音

片假名常用长音符号：コーヒー = koohii。平假名则加元音：おかあさん、おにいさん。

ゃゅょ
小写拗音

跟い段假名组成一个拍：きゃ = kya，不是 ki + ya 两拍。

ぁぃぅぇぉ
小写元音

多用于外来语：ファ fa、フィ fi、ウェ we、フォ fo。

⑥ 外来语常见扩展 片假名

平假名写日语本身和语法；片假名写外来语、拟声词、强调。读音采用赫本式：し=shi、ち=chi、つ=tsu、ふ=fu。

易混假名

容易混怎么记
ね / れ / わね 有一弯钩；れ 是竖折；わ 开口更大。
ぬ / めぬ 像「ぬ」里有个圈（ぬの的线穿过）；め 更像眼睛。
さ / き　ち / らさ 左右可断开；き 多一横。ち 像数字 5；ら 起笔更弯。
シ / ツ　ソ / ン片假名：シ 点向右下、ツ 点向下；ソ 一撇较短，ン 更平。
ア / マ　ク / タア 像尖帽子；マ 有横折。ク 开口向右，タ 多一折。
